# Menjalankan Seblak Prasmanan di Expo Go

## Sebelum menjalankan
1. Ekstrak ZIP ini.
2. Buka folder `KedaiSeblak` di VS Code (folder yang berisi `package.json`).
3. Pastikan Node.js sudah terpasang.

## Perintah
Jalankan di terminal VS Code:

```bash
npm install
npx expo start --clear
```

4. Pastikan HP dan laptop terhubung ke jaringan Wi-Fi yang sama.
5. Buka aplikasi Expo Go di HP lalu scan QR yang tampil di terminal/browser.
6. Jika jaringan lokal bermasalah, jalankan `npx expo start --tunnel --clear`.

## Catatan tampilan HP
- Tabel yang lebih lebar daripada layar HP dapat digeser ke kiri/kanan; itu disengaja agar kolom tidak saling menimpa.
- Halaman panjang dapat digulir ke bawah.
- Akun demo: Kasir (`Siti Aisyah` / `kasir123`), Owner (`Dewi` / `owner123`).
- Pembayaran QRIS pada proyek ini masih simulasi untuk demonstrasi UI.
